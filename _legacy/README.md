# `_legacy/` — 過去機能のアーカイブ

機能撤廃済だが互換維持のため残置している legacy スクリプト群。

## 含まれるファイル

### `gasshuku.js` (合宿ガチャ機能、 2026-04-30 機能撤廃)

- **元用途**: DIK 合宿期間限定ガチャ (合宿期間中の限定キャラ排出 + 期間中ホーム CTA + 合宿カットイン演出)
- **現在の状態**: `isGasshukuActive() = false` で機能無効化済 (2026-05-06、 v1.5.1)
- **残置理由**: 4/30 23:59 までにアカウント作成済のユーザーが、 図鑑タブ「期間限定」 から合宿キャラを **閲覧のみ** できるよう判定ロジックを保持
- **今後**: 4/30 前 account がいなくなったタイミングで完全削除可能

## index.html からの参照

`<script src="/_legacy/gasshuku.js?v=...">` で読み込み中。 _legacy 配下に置いても script タグ含めて 通常通り動作。
