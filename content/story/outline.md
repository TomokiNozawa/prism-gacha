# 🌅 Season 1: 観測の時代

世界の現状を描く章群。プリズマと七座が世界を維持する古い秩序。終盤、プリズマは「次の大紀」のため眠りに入る。

## S1C1: 序 — 七座の使命
- **POV**: ちさと (星霊学院 剣術科 一年生)
- **規模**: 30キャラ (現キャラ全員)
- **あらすじ**: 平凡な学院生ちさとが、影喰いの群れに学院近郊で遭遇。学院四人組(ちさと/カイ/アルス/ミレイア)+α(こはね)で立ち向かおうとするが力及ばず。そこに白焔教会のイザベル、夜焔郷の朱音、紅翼皇家のひなたら大人キャラが救援に駆けつける。最後に黄昏色の光が現れ、プリズマの化身が「次の世代に託す」と告げて消える。
- **山場**: ちさとが初めて自分の虹脈に気づく — 涙ながらの覚醒シーン
- **テーマ**: 誰もが原虹の一筋を持つ。世界はあなたから始まる
- **Season跨ぎ伏線**: プリズマの「眠りに入る」予兆 → S1C7

## S1C2: 南方海域の異変
- **POV**: イザベル (白焔教会 聖巫騎士)
- **規模**: 15キャラ (海淵都市 + 海賊 + 補助)
- **tier配分**: UR 2 / SSR 3 / SR 5 / R 5
- **UR2体**: ネプテア(深海女王/新派閥頂点) + 波紋の聖女イザベル(覚醒形・別エントリ)
- **あらすじ**: 教会の使者として南方海域の海淵都市アクアシスへ派遣されたイザベル。海中の影喰いが商船を襲い始めている。紅玉海賊団のシャンティ、深海女王ネプテアと出会い、共闘。「神は陸の上だけにいるのか?」と問われ、自分のあり方を問い直す。
- **山場**: イザベルが「セラフィエル様の代理」ではなく「自分自身として祈る」ことに気づく瞬間 — **聖槍『天穹』が虹色の波紋を海中に放ち、聖巫騎士イザベル(SSR)が『波紋の聖女』(UR)へと覚醒**。SSR版とは別エントリとして図鑑に追加される設計
- **テーマ**: 信じる対象は、外にあるとは限らない
- **新派閥**: 海淵都市アクアシス / 紅玉海賊団
- **Season跨ぎ伏線**: ネプテアが「黒月の前兆」を海から観測している → S1C5/C7 / 波紋の聖女イザベルは S1C7 黒月決戦の七座級戦力として再登場

## S1C3: 砂塵の隊商
- **POV**: ヴィル (紫竜王国 第三王女)
- **規模**: 10キャラ (古龍砂漠 + 補助)
- **あらすじ**: 「竜の血」を辿るため、紫竜王国を抜け出して古龍砂漠サハールへ。砂漠の遊牧王女サハナと出会う。古龍の末裔ファラーから「失われた古龍王」の存在を知らされる。ヴィルは「血の繋がり」より「選んだ家族」が重要だと知る。
- **山場**: ヴィルとサハナが共に夜空の星を見上げて、それぞれの孤独を打ち明ける場面
- **テーマ**: 血ではなく、共に過ごした時間が家族を作る
- **新派閥**: 古龍砂漠サハール
- **Season跨ぎ伏線**: 失われた古龍王 → S2 で覚醒予定

## S1C4: 凍土と空
- **POV**: アルテミス (龍国 龍帝)
- **規模**: 20キャラ (氷霊王国 + 空挺城 + 補助)
- **あらすじ**: 龍帝として外交で氷霊王国ニーヴルへ。氷帝グレイル(若き帝、第三の覇者候補)と一騎打ちで引き分け、互いを認め合う。空挺城ゼノニアとの同盟交渉も行う。アルテミスは「覇王として君臨することの孤独」を感じる。回想で戦友ヒノオウとの過去 (二十歳の頃、 同じ影喰いを背中合わせで斬り伏せた戦場) が描かれる。
- **山場**: グレイルとの一騎打ち後、二人で雪原に並んで空を見上げる無言の時間
- **テーマ**: 強者の頂は、孤独を共に分かち合うことで初めて温かい
- **新派閥**: 氷霊王国ニーヴル / 空挺城ゼノニア
- **Season跨ぎ伏線**: アルテミスが「次に龍を譲る相手」を考え始める → S2 龍帝退位への布石

## S1C6: 七座満つる
- **POV**: セラフィエル (観測者七座 第一席)
- **規模**: 20キャラ (巫女連邦 + 観測者新席)
- **あらすじ**: 七座の空席が次々埋まり始める。第四席「約束」に巫女連邦のイリスが選ばれる。三柱が儀式の場でイリスを正式に「七座の同胞」 として迎え入れ、 七座満つる時代の幕が上がる。
- **山場**: 七座の四人 (三柱 + イリス) が初めて同じ場所に揃う神殿の場面 — それぞれ違う方向を向きながらも、 「世界を守る」 という一点だけは共有している
- **テーマ**: 違っていても、同じ目的を持つ仲間でいられる
- **新派閥**: 巫女連邦リーリエ
- **UR3**: イリス (第四席「約束」 着座者、 21歳) / ヴィオレナ (イリスの実母、 約半世紀前に第四席候補を辞退した巫女連邦の長老) / 鳳神巫女ホムラ (巫女連邦最強の戦巫女、 七座警護頂点格、 27歳)
- **Season跨ぎ伏線**: ノクスが「これでも足りない」と呟く — 第七席「沈黙」の必要性 → S3 / セラフィエル翼を一枚畳む準備 → S1C7・S2C7 / カグヤ千年日記 → S2C4 / イリス継承血脈 → S2C6

### 観測者七座の 設定 (s1c1〜s1c6 一貫)
- **席順 = 七色の祈りの 役割の順** (赤=祈り → 橙=記憶 → 黄=未来 → 緑=約束 → 青=連結 → 藍=忘却 → 紫=沈黙)、 **力の上下や 古さの順ではない**
- **主席 (中央) = プリズマ** = 七座主席、 万物の意志、 もうすぐ眠る (s1c7)
- **第一席 = セラフィエル** (赤・祈り) = プリズマが**自ら生み出した「最初の羽」**、 千年前から 観測者として在る
- **第二席 = カグヤ** (橙・記憶) = 月の化身、 「**原虹の誕生より前から在る**」 (POOL desc 確定)、 古文調「じゃ」「お主」
- **第三席 = ノクス** (黄・未来) = 星海のノクス、 古き観測者、 予知、 短文鋭い
- **第四席 = イリス** (緑・約束) = 21歳、 s1c6 で着座、 巫女連邦の継承血脈の最新の枝
- **第五〜七席** (青連結・藍忘却・紫沈黙) = 未着座、 S2-S3 で順次
- **重要**: **カグヤとノクスは プリズマが生み出したのではなく、 原虹の頃から プリズマと並んで在った 古き同胞**。 セラフィエルは その後に プリズマが「最初の羽」 として生み出した。 カグヤ・ノクスが セラフィエルに「お前」「お主」 と呼ぶのは 古き同胞が 妹のように親しく呼びかけるニュアンス
- 「千年に一度 1人ずつ 七座が満ちる」 設定は **ない** (= 着座は 不定期、 必要に応じて)

### 巫女連邦 設定 (s1c6 確定)
- **派閥**: 巫女連邦リーリエ、 古来から続く 第四席「約束」 を司る巫女集団
- **継承血脈**: 巫女連邦の代表巫女系譜、 通常人間の母娘継承 (= 各代 数十年スパン)
- **第四席候補**: 過去 何代もの代表巫女が 候補に挙がるが、 皆 辞退してきた
- **ヴィオレナ**: 約半世紀前 第四席候補辞退、 巫女連邦の長老。 「私の娘が、いずれ私の代わりに座る」 と告げ、 約三十年の長き祭祀を経て 晩年に直接娘イリスを産み、 二十一年育てた
- **千年級 vs 半世紀級 対比**: リオラエル殿 (s1c5、 千年級) と ヴィオレナ (s1c6、 半世紀級長老) は 別々の夜に 月影宮を訪れて 観測者七座を辞退した「系譜の重なり」 (= s1c6 3-3 カグヤ千年日記参照)
- **儀式の場**: 第四席着座儀式は **月影宮の常夜の卓**で 観測者四柱 (三柱+新着座者) で行う、 **巫女連邦主祭リアラは 一夜限りの特例で月影宮へ招かれて儀典官を務める**
- **鳳神巫女ホムラ**: 巫女連邦の戦巫女頂点、 数代続く鳳神巫女の血脈、 過去三代も第五席候補に挙がるが 全て辞退、 焔帝ヒノオウ (千年級) の鳳凰と同じ祈りから生まれた 継承職能を担う

### 千年表現の使い分け (重要 — 全章整合)
- **千年級キャラ**: プリズマ / ヴォイドラ / アルテミス / ヒノオウ / ファラー / ネプテア / カグヤ / ノクス / セラフィエル / リオラエル殿 / ザナディア / ノクトリア / 異界塔ザナド系列 = 「千年」 表現維持
- **千年級でないキャラ**: ヴィオレナ (半世紀級長老) / ホムラ (27歳通常人間) / 巫女連邦SR/R = 「千年職能 → 継承職能」「千年血脈 → 継承血脈」「千年祭祀 → 巫女連邦祭祀」

# 🌃 Season 2: 接続の時代

プリズマ眠った世界。並行世界との「接続」が始まり、Season 1キャラの「もう一人の自分(並行同位体)」が出現する章群。

## S2C1: 眠れる主の世界
- **POV**: シ・ロエン (S1で分離した影シオン)
- **規模**: 20キャラ (S1進化版 + 新)
- **あらすじ**: プリズマ不在の世界で起きる小さな歪み。シ・ロエンが裏側から世界の安定に尽力。S1キャラの一部が「失われた」状態 (記憶喪失や封印)。
- **山場**: シ・ロエンとシオンが再会、互いに知らない自分を学ぶ
- **テーマ**: 主人公不在でも、世界は続く
- **Season跨ぎ伏線**: プリズマの夢の中で「もう一つの世界」が見え始める

## S2C2: 鏡の世界
- **POV**: ノクス
- **規模**: 15キャラ (並行同位体)
- **あらすじ**: 並行世界との接続が始まり、Season 1キャラの「もう一人の自分」が出現。例: 暗黒IFアルテミス、戦巫女リナエ など。それぞれの世界線での選択の違いが描かれる。
- **山場**: ノクスが「これは私が見ていた未来の一つに過ぎない」と告げる
- **テーマ**: 選ばれなかった可能性も、確かに存在した
- **新タイプ**: parallel (並行同位体)

## S2C3: 沈黙の塔
- **POV**: 第七席候補 (新キャラ・名は仮)
- **規模**: 15キャラ
- **あらすじ**: 観測者第七席「沈黙」の候補が次々に現れる。元観測者派閥「沈黙の塔」も登場。
- **山場**: 候補者たちが「沈黙とは何か」を体現する試練
- **テーマ**: 語らないことにも意味がある
- **新派閥**: 沈黙の塔

## S2C4: 記憶の海
- **POV**: カグヤ
- **規模**: 20キャラ (過去編キャラ多数)
- **あらすじ**: カグヤの千年記憶の海に潜入。過去のキャラ達が登場 (過去編との接続)。プリズマ生誕の瞬間も描かれる。
- **山場**: 千年前のヒノオウ、若き日のアルテミスが登場
- **テーマ**: 記憶は失われない、ただ眠っているだけ
- **過去編接続**

## S2C5: 影との和解
- **POV**: ヴォイドラ (POV移動)
- **規模**: 15キャラ
- **あらすじ**: ヴォイドラ陣営との対話と和解の試み。シ・ロエン、ノクトリア、ガルヴィン (元・教会/月牙) が交渉役に。
- **山場**: ヴォイドラが「私も観測されたかっただけ」と告白
- **テーマ**: 敵にも理由がある

## S2C6: 新たな七座
- **POV**: イリス + 残席候補
- **規模**: 20キャラ
- **あらすじ**: 七座が次々完成し始める。第五席「連結」、第六席「忘却」が埋まる。
- **山場**: 五座+六座が同時に着席する儀式
- **テーマ**: 系統の継承

## S2C7: 接続の儀
- **POV**: 全観測者
- **規模**: 30キャラ
- **あらすじ**: 並行世界統合儀式。プリズマ覚醒、ヴォイドラと「共観」を提唱。Season 2の決戦というより「儀式」。
- **山場**: 全Season1+S2キャラ集結、虹色と黒色が混じる新色「**共観の灰**」が世界に満ちる
- **テーマ**: 二元論を超える瞬間
- **Season跨ぎ伏線**: Season 3 「超越の時代」へ
