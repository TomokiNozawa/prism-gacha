## 楽曲コンセプト

異界の塔ザナド派閥の音楽。 章 BGM (Prism Voidrad) が「ヴォイドラ覚醒+全派閥決戦+共観の融合+眠り」 の動的な三層展開 (戦場全体のドラマ) を担うのに対し、 派閥 BGM は **異界塔ザナドそのもの** = 千年祈りを守ってきた影の文明が ようやく目覚め 動き出す力強い覚醒・古代の威厳・解放された塔の脈動 を表現する。 千年前にヴォイドラを召喚し、 千年閉じ込めの責を負って共に時を止めた異界塔ザナドの民は、 ただ静かに祈っていたのではなく、 「いずれ動き出す日」 を信じて千年の儀式・鍛冶・歌・偵察・伝令の文化を磨き続けてきた。 図鑑/相関図で異界塔ザナドのキャラ (ヴォイドラ・ザナディア・ウンブリス・テネブラ・ジュンクトス・オブスクル・ノクサル・アビス・グリム・ニュトラル・ヴィタ・ザイ・メル) を眺める時、 「千年祈りが ようやく動き出した古代影文明の雄大な威厳」 が立ち上がる構成。 静謐ではなく **力強い覚醒系**、 暗いだけではなく **誇り高い古代の脈動**。

## 🎵 v1 — High-tempo Millennium Awakening Void Liberation (BPM 140、 推奨基準)

- **基調**: pipe organ (heroic ascending motif) + driving low strings (cello+viola tremolo) + low/high brass (trumpets + French horns) + void male choir (energetic dignified) + taiko-style drums + obsidian percussion + crystal singing bowl + 高速 timpani
- **ムード**: 千年閉じ込められた影の文明が ようやく目覚め 動き出す雄大な威厳 + 駆動力 + 古代の脈動 + 解放された塔そのものの力強さ (静謐ではなく覚醒、 暗いけれど誇り高い)
- **テンポ**: 高速 (BPM 130-150、 派閥 BGM アップテンポ既定範囲、 千年祈りが ようやく形を取って動き出す pulse)
- **構成**: 低 pipe organ + obsidian percussion 冒頭 (千年塔の目覚めの胎動) → driving low strings tremolo + horns 重なり (覚醒の build) → pipe organ ascending heroic motif (千年祈りが立ち上がる) → taiko + timpani 高速脈動 + void choir energetic (古代儀式の覚醒) → 山場 (pipe organ + 全 brass + void choir + taiko + 全層) → 余韻 (高速のまま静かに次へ、 動き出した塔の脈は止まらない)

## 整合性 (章 BGM + 既存派閥 BGM との差別化)

- 派閥のテーマ: 異界の塔ザナドの **千年祈りから解放される影の文明・力強い覚醒の威厳・古代の脈動・誇り高い目覚め** (外面=塔そのものが動き出す印象)
- 章 BGM (prism-voidrad) との差別化:
  - prism-voidrad (BPM 145 三層): 戦闘+神聖+静謐 動的展開、 二元論超越の融合儀式 (戦場全体のドラマ)

  - 楽器面: 章 = 三層変化 (brass+timpani / 二極 choir / piano+harp) / 派閥 = 単極駆動 (pipe organ + 低弦 tremolo + brass + taiko)
  - ムード面: 章 = 動的最終決戦のドラマ / 派閥 = 動的覚醒の威厳 (どちらも高速だが、 章=戦場 / 派閥=塔)
- 既存派閥 BGM との差別化:
  - prism-church (church BPM 70 processional): 教会聖歌 vs voidtower 古代覚醒、 速度・暗さで完全独立
  - prism-aquasis (aquasis BPM 60 underwater): 海中神秘 vs voidtower 古代影、 全く別世界
  - prism-crimson (crimson BPM 130+ pirate): 海賊シーシャンティ vs voidtower 古代讃美、 楽器系統で独立
  - prism-niflheim (niiruru BPM 112 mystic-orchestral): 氷霊神秘 vs voidtower 影覚醒、 配色・温度が逆 (ニーヴル=寒+清/voidtower=暗+古)
  - prism-zenonia (zenonia BPM 130 steampunk): 機械文明 vs voidtower 古代文明、 楽器系統で独立 (steampunk vs ancient-organ)
  - prism-frostcrown (silver BPM 130 royal-martial): 王国威風 vs voidtower 古代覚醒、 royal-martial vs ancient-heroic で独立
  - prism-sahar (sahar BPM 110 desert-mystic): 砂漠民俗 vs voidtower 古代影、 配色 (砂金/紫黒)+楽器で独立
  - prism-kagura (lirie faction_lirie BPM 120 神楽): 巫女連邦の祝祭神楽 vs voidtower 古代覚醒讃美、 ムード逆転 (祝祭/解放) でも速度近く 楽器系統で独立
- 例外路線: voidtower は **唯一の「目覚めた古代影の文明」 派閥** という独自ニッチ、 既存の生きた派閥群 (祝祭・戦士・神官系) とは時間軸が違う (千年祈りの解放系)
- 異界の塔ザナドの世界観要素を全て音楽要素に翻訳: 異界塔の覚醒 (low pipe organ + obsidian pulse) / 古代讃美歌の解放 (heroic ascending pipe organ + void choir) / 千年祈りの動き出し (driving low strings tremolo + brass) / 解放された塔の脈動 (taiko + timpani) / 千年磨いた儀式 (obsidian percussion + crystal bowl) / ヴォイドラの覚醒 (全層の重さと駆動力)
