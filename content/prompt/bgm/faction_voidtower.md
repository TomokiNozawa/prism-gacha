## 楽曲コンセプト

異界の塔ザナド派閥の音楽。 章 BGM (Prism Voidrad) が「ヴォイドラ覚醒+全派閥決戦+共観の融合+眠り」 の動的な三層展開を担うのに対し、 派閥 BGM は **異界塔ザナドそのもの** = 千年閉じ込められた影の文明の静謐な威厳・失われた古代の格・ザナディア (UR 千年級塔主) が刻んできた千年の祈り を表現する。 千年前にヴォイドラを召喚し、 千年閉じ込めの責を負って共に時を止めた異界塔ザナドの民の文化、 影と共に生きる文明 (リオラエル殿の地底市リオラ s1c5 とは異なる、 「光を捨てた」 のではなく「光を観られなかった」 文明)。 図鑑/相関図で異界塔ザナドのキャラ (ヴォイドラ・ザナディア・ウンブリス・テネブラ・ジュンクトス・オブスクル・ノクサル・アビス・グリム・ニュトラル・ヴィタ・ザイ・メル) を眺める時、 「千年止まった時間と古代神秘の静謐」 が立ち上がる構成。

## 🎵 v1 — Mid-tempo Millennium Imprisoned Void Solemn (BPM 100、 推奨基準)

- **基調**: 低弦 + pipe organ + void male choir + 暗い harp + crystal singing bowl + obsidian percussion + 遠い brass drone
- **ムード**: 千年閉じ込められた影の文明の静謐な威厳 + 失われた古代の格 + 時間が止まった印象 + 暗いけれど絶望ではない (千年祈り続けてきた塔の民の品位)
- **テンポ**: 中速 (BPM 95-110、 派閥 BGM 推奨範囲、 千年止まった時間を反映した遅すぎず速すぎない pulse)
- **構成**: void rumble 冒頭 (千年塔の目覚めない深層) → pipe organ 古代讃美主題 (失われた文明の格) → 低弦と void choir 重なり (千年閉じ込めの祈り) → crystal bowl 揺らぎ + obsidian percussion (古代儀式の脈) → 山場 (pipe organ + void choir + 全層) → 余韻 distant brass drone lingering (千年続く沈黙)

## 整合性 (章 BGM + 既存派閥 BGM との差別化)

- 派閥のテーマ: 異界の塔ザナドの **千年幽閉された影の文明・静謐な威厳・失われた古代の格・時間が止まった印象** (外面=塔そのものの空気感)
- 章 BGM (prism-voidrad) との差別化:
  - prism-voidrad (BPM 145 三層): 戦闘+神聖+静謐 動的展開、 二元論超越の融合儀式
  - prism-zanado (BPM 100 単極): 千年止まった時間の静謐な威厳、 動的展開なし、 単極の古代神秘
  - 楽器面: 章 = 三層変化 (brass+timpani / 二極 choir / piano+harp) / 派閥 = 単極古代 (pipe organ + 低弦 + void choir + crystal bowl)
  - ムード面: 章 = 動的最終決戦のドラマ / 派閥 = 静的千年塔の威厳
- 既存派閥 BGM との差別化:
  - prism-church (church BPM 70 processional): 教会聖歌 vs voidtower 失われた古代讃美、 楽器の重み・暗さで完全独立
  - prism-aquasis (aquasis BPM 60 underwater): 海中神秘 vs voidtower 古代影、 全く別世界
  - prism-crimson (crimson BPM 130+ pirate): 海賊シーシャンティ vs voidtower 古代静謐、 完全別路線
  - prism-niflheim (niiruru BPM 112 mystic-orchestral): 氷霊神秘 vs voidtower 影神秘、 配色・温度が逆 (ニーヴル=寒+清/voidtower=暗+古)
  - prism-zenonia (zenonia BPM 130 steampunk): 機械文明 vs voidtower 古代文明、 完全独立
  - prism-frostcrown (silver BPM 130 royal-martial): 王国威風 vs voidtower 古代静謐、 動的 vs 静的で独立
  - prism-sahar (sahar BPM 110 desert-mystic): 砂漠民俗 vs voidtower 古代閉じ込め、 配色 (砂金/紫黒)+楽器で独立
  - prism-kagura (lirie faction_lirie BPM 120 神楽): 巫女連邦の祝祭神楽 vs voidtower 失われた古代讃美、 ムード逆転 (祝祭/葬送)
- 例外路線: voidtower は **唯一の「失われた古代影の文明」 派閥** という独自ニッチ、 既存の生きた派閥群とは時間軸が違う (千年止まった文明)
- 異界の塔ザナドの世界観要素を全て音楽要素に翻訳: 異界塔の覚醒 (void rumble) / 古代讃美歌 (pipe organ) / 千年祈り (void choir) / 失われた文明の静謐 (crystal bowl) / 古代儀式 (obsidian percussion) / 千年止まった時間 (distant brass drone) / ヴォイドラの存在感 (低弦 + 全層の重さ)
